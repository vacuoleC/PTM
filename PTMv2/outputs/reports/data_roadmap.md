# PTMv2 数据路线图（E5）

**日期**：2026-08-09
**状态**：基于 E3.1（置换 null）、E3.2（学习曲线双轨）、E4（探索性比较）的已完成证据

## 1. 核心结论回顾

| 证据 | 结果 | 含义 |
|---|---|---|
| E3.1 置换 null（500 次，fixed-params） | p=0.341（170/500 ≥ observed 0.4646） | 主模型未通过置换检验 |
| E3.2 学习曲线（pca 轨，30 cells） | 0.446 → 0.455 → 0.463（上升） | 样本量增加 → 性能上升 |
| E3.2 学习曲线（raw 轨） | 进行中（4/30 cells） | 待互证 |
| E4 SVD-SVM（探索性） | mean oof_ap=0.5475 | SVD 空间有信号 |
| E4 UMAP（探索性） | mean oof_ap=0.4626 | 微弱信号 |
| 随机基线 | 0.4528 | 正类比例 |

**综合判定**：
> **LSCC G2 vs G3 在当前 106 患者、6 万 PTM 位点表示下不可稳定建模（p=0.341），但学习曲线上升提示数据量不足是主因；探索性 SVD 表示显示信号存在。**

## 2. 失败边界（当前方案的局限）

### 2.1 统计层面
- **小样本**：106 患者（G2=58 / G3=48），每折测试仅 ~21 患者 → AUPRC 逐折噪声大（std ~0.05）
- **置换检验未过**：p=0.341，observed 仅比 null 中心高 0.016（0.4646 vs 0.4486）
- **效应量小**：即使真实信号存在，当前样本下效应量不足以达显著

### 2.2 特征层面
- **6 万 PTM 位点**（磷酸化 72,361 + 乙酰化 19,331），检测率低（磷酸化平均 0.356、乙酰化 0.411）
- **大量缺失**：检测率 ≥0.1 后保留 ~60,534 特征，但多数位点仅部分患者测得
- **表示选择**：PCA 降维（E3.1 用）与 raw（E3.2）结果一致——表示差异不改变主结论

### 2.3 计算层面
- CPU cgroup 4 核限制 → 全嵌套置换不可行（GPU 固定超参方案是唯一 24h 内路径）
- 求解器差异（saga vs cuml-qn）引入 ~0.03 OOF 分数噪声

## 3. 数据需求（量化）

基于学习曲线趋势（pca 轨 0.446→0.463，斜率 ~0.03/0.5 样本）：

| 样本量 | 外推 AUPRC（线性） | 能否达显著（p≤0.05）？ |
|---|---|---|
| 106（当前） | 0.463 | ❌（p=0.341） |
| ~200 | 0.478 | 可能（效应量 ~0.03，SE 减半） |
| ~400 | 0.493 | 可能 |
| ~800 | 0.508 | 更可能 |

**注意**：线性外推是乐观假设（学习曲线通常饱和）。保守估计需 **300-500 新增患者**（G2/G3 平衡）才可能达显著。

## 4. 真实配对条件（多视图 E6 前提）

- 多视图（E6）仅在**真实患者级磷酸化/乙酰化配对**存在时开启
- 当前数据：磷酸化与乙酰化是**不同患者群**（无配对）→ **E6 不启动**（有证据的"不启动"记录）
- 需新数据：同一患者的磷酸化 + 乙酰化双测量

## 5. 可能的数据来源（建议）

| 来源 | 类型 | 可行性 |

| CPTAC LSCC 扩展队列 | 同队列更多样本 | 高（同一检测平台） |

## 6. Encoder 重新开门判定

**当前判定：不重新开门。**

冻结规则：仅当（a）计量兼容的无标签预训练来源存在，或（b）学习曲线显示稳定增益时才重新评估深度 encoder。

- **学习曲线**：pca 轨上升（0.446→0.463）——**这是"稳定增益"的初步证据**，但幅度小（0.017），且 raw 轨未完成互证
- **无标签预训练来源**：当前无计量兼容的 PTM 大规模无标签数据

**建议**：**条件性重新开门**——
- 若 raw 轨学习曲线完成且同样上升（双轨互证）→ 标记"学习曲线显示增益"，encoder 重新开门**部分满足**
- 但**无预训练数据**仍不满足 → 保持关闭，除非获得大规模无标签 PTM 数据

## 7. 建议路线

1. **短期**：扩大 LSCC 队列至 200-300 患者（CPTAC 扩展），重跑主分析
2. **中期**：探索 SVD 表示（E4 显示 0.5475）在更大样本上的稳定性
3. **长期**：若获得大规模无标签 PTM 数据 → 重新评估 encoder（重新开门条件满足）

## 8. 附注

- 探索性结果（SVD/UMAP）**不改变主结论**（冻结规则），仅作为未来方向线索
- 本路线图的量化外推（样本量→AUPRC）是**初步估计**，需更大样本验证
