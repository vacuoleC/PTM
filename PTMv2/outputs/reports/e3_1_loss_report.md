## 三、无效尝试与根因

| 无效尝试 | 根因 |
|---|---|
| 单核 500 置换 | 未先测速就启动全量，低估计算量 100 倍 |
| 3/60 核烟雾 | 嵌套（内层选择）工作量被漏算——4100 次拟合而非 131 次 |
| 观察值嵌套 12h 未完 | 嵌套串行 + 6 万特征 saga（85s/拟合） |
| GPU 尝试 1（cuML） | cuML 与 saga 收敛到不同解（fold3 diff 0.09） |
| GPU 尝试 2（L-BFGS） | torch L-BFGS 高维假收敛（F 高 20%） |
| GPU 尝试 3-4（cuML 紧收敛） | cuML qn 难折收敛死循环 |
| GPU 尝试 5（PCA30） | Spearman 0.9494 差 0.0006 未达标 |

**共同教训**：
1. **先测速后全量**——单次拟合实测（266.5s）本应在启动任何作业前做
2. **嵌套工作量 = 外层折 ×（候选 × 内层折 + 1）**，不是外层折 × 1
3. **max-hours 只约束置换阶段**，嵌套阶段无上限（代码缺陷，已在新运行器修正）
4. GPU 优化器与 saga 的一致性在 22 样本测试集上极难 ≤0.01（AUPRC 对排序微变敏感）

## 四、有效发现（损失中的收获）

1. **PCA 降维是核心解**：6 万特征 → 20 维，saga 单次 266s → 1.45s（4000×），500 置换 16h 可完成

3. **cuML 与 saga 排序高度一致**（Spearman ≥0.98）：GPU 路径技术上可行，PCA22 全过（待变更）
4. **checkpoint 接力机制**：即使中断也可恢复（已实现）
